# CloudCannon Editing Guide - 1460 Dental Studio

## How to Edit Your Site

### Main Pages
All main website pages can be found and edited in the **Pages** section:

- **Home Page** (`index.astro`) - The main landing page
- **About Page** (`about.astro`) - Practice and doctor information
- **Services Page** (`services.astro`) - Dental services offered
- **Contact Page** (`contact.astro`) - Contact information and forms

### Editing Pages
1. Click on any page in the **Pages** section
2. Use the **Visual Editor** to edit content directly on the page
3. Use the **Content Editor** for structured editing
4. Use the **Source Editor** for advanced HTML/code editing

### Site Settings
Global site information can be edited in **Data** > **Site Settings**:
- Practice information (phone, address, hours)
- Social media links
- SEO settings
- Doctor and practice details

### Page Settings
Each page has editable front matter for:
- **Title** - The page title that appears in browser tabs and search results
- **Description** - Meta description for SEO and search results
- **Layout** - The page template (usually BaseLayout)

### Content Areas
Most pages have the following editable sections:
- Hero sections with titles and descriptions
- Main content areas
- Call-to-action sections
- Contact information

### Images
- Upload images through the CloudCannon interface
- Images are stored in the `/images/` folder
- Use descriptive alt text for accessibility

### Best Practices
1. **Always preview changes** before publishing
2. **Keep titles under 60 characters** for better SEO
3. **Keep descriptions under 160 characters** for search results
4. **Use consistent terminology** throughout the site
5. **Test contact forms** after making changes

### Support
If you need help with editing, the site structure supports:
- Visual editing for most content
- Form editing for contact information
- Image management through CloudCannon
- SEO optimization tools

### Template Structure
All pages use the same **BaseLayout** template, which includes:
- Site-wide navigation
- Footer with contact information
- SEO meta tags
- Responsive design

This ensures consistency across all pages while allowing easy content editing.
